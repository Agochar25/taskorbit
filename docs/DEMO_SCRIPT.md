# 5-minute screen recording script

Record your PC screen with the Android emulator (or a mirrored phone, e.g. `scrcpy`) side by side.

1. **0:00** Show the deployed web URL and the Android app. Say the one-line pitch.
2. **0:30** Register `demo-<yourname>@example.com` on the **web**. Show the empty dashboard.
3. **1:00** Create a project with dates, then add 3 tasks with different priorities and due dates (one overdue, one due tomorrow).
4. **2:00** Open the **Android** app, log in with the **same** account. Show the same dashboard and project (pull-to-refresh).
5. **2:45** On **mobile**, create a task "Created on my phone". Switch to the web, refresh: it appears.
6. **3:30** On the web, drag a task to *Completed* on the Board. Pull-to-refresh on mobile: status updated; show filters and search on both.
7. **4:15** Quick security demo: log out; show the offline banner (airplane mode) with saved tasks; mention token in Keystore, bcrypt, rate limit.
8. **4:45** Show the GitHub repo, README and `docs/API.md`.
